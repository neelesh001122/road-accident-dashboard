# 🚗 Road Accident Analysis Dashboard

An end-to-end interactive Excel and Web-based Data Visualization Dashboard analyzing road accident data for **2021 and 2022** to extract actionable safety insights for key stakeholders.

🔗 **Live Interactive Dashboard:** [View Dashboard](https://neelesh001122.github.io/road-accident-dashboard/)

---

## 📌 Project Overview & End-to-End Steps

This project was developed following a structured data analytics workflow to solve client requirements:

1. **Requirement Gathering:** Defined key metrics, timelines, and reporting needs with the client.
2. **Stakeholder Identification:** Identified key organizational end-users to tailor the visual presentation.
3. **Data Cleaning:** Cleaned raw data, handled missing values, and standardized fields.
4. **Data Processing:** Added custom calculated columns and logic to prepare data for comparative temporal analysis.
5. **Data Analysis:** Performed deep data exploration using Excel Pivot Tables, DAX/Advanced Excel Functions, and logic modeling.
6. **Data Visualization:** Designed custom sheets, interactive cards, and charts for intuitive insights.
7. **Dashboard Creation:** Built a fully dynamic, end-to-end interactive dashboard with responsive slicers.

---

## 🎯 Key Requirements & Dashboard KPIs

### Primary KPIs
* **Total Casualties:** Overall accident casualties across all recorded incidents.
* **Casualties & Percentage by Severity:** Breakdown and percentage distribution across **Fatal**, **Serious**, and **Slight** casualties.
* **Maximum Casualties by Vehicle Type:** Identifying high-risk transport modes.

### Secondary KPIs
* **Monthly Trend Analysis:** Comparative visual trend line of casualties for **Current Year vs. Previous Year**.
* **Casualties by Road Type:** Highlighting accident frequencies across Single carriageways, Dual carriageways, Roundabouts, etc.
* **Casualties by Road Surface:** Distribution across Dry, Wet, and Snow/Ice conditions.
* **Location & Lighting Insights:** Relationship between casualties by **Area Type (Urban vs. Rural)** and **Light Conditions (Daylight vs. Dark)**.

## 📊 Dataset Specifications

* **File Format:** `.xlsx` (Excel Workbook)
* **Dataset Size:** ~307,974 rows (3.07+ million entries analyzed)
* **Fields/Columns:** 21 attributes detailing severity, location, road types, weather, and casualties.
