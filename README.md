# 🚗 Road Accident Analysis Dashboard

An interactive Excel and Web-based Data Visualization Dashboard analyzing road accident data to identify key metrics, trends, and safety insights.

🔗 **Live Interactive Dashboard:** [View Dashboard](https://neelesh001122.github.io/road-accident-dashboard/)

---

## 📊 Project Overview

This project focuses on analyzing road accident statistics to provide insights into accident severity, casualties by vehicle types, monthly trends, and environmental conditions (road surface and light conditions). The dashboard allows stakeholders and analysts to filter data dynamically for strategic decision-making.

---

## Key Features & KPIs

* **Total Casualties:** Overall accident casualty count.
* **Casualty Severity Breakdown:** Fatal, Serious, and Slight casualties with percentage distribution.
* **Vehicle Type Analysis:** Casualties categorized by Cars, Vans, Buses, Bikes, Tractors, and others.
* **Monthly Trend Analysis:** Current Year vs. Previous Year comparative line chart analysis.
* **Road & Environmental Insights:** Breakdown by Road Type, Light Conditions, and Surface Conditions.
* **Dynamic Slicers:** Interactive filters for years and location/area types (Urban vs. Rural).

---

## 🛠️ Tech Stack & Tools Used

* **Data Analysis & Visualization:** Microsoft Excel (Pivot Tables, Advanced Formulas, Slicers)
* **Cloud & Hosting:** Microsoft OneDrive / Excel Online, GitHub Pages
* **Web Integration:** HTML5, CSS3
